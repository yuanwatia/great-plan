# 密钥与 .env

## 一句话

**`.env` 是装钥匙的抽屉，本地必须有，但绝不能上传。**

## 为什么要写进 .gitignore

程序运行要用到 API key、数据库密码、令牌之类的东西，都放在 `.env` 里。
GitHub 上的仓库（尤其 public）谁都能看，一旦推上去就等于把钥匙挂在电线杆上——
别人可以拿你的额度去跑任务，账单算你头上。

所以规矩是：

1. `.env` 写进 `.gitignore`，让 git 装作看不见它
2. 仓库里只放一份 `.env.example`（把 key 的位置留空），告诉别人要填什么
3. 万一已经提交过：`git rm --cached .env` 把它从版本库踢出去，再补进 `.gitignore`

## 记忆点

- `.gitignore` 只能挡住**还没被提交过**的文件
- 密钥要轮换（重置）时，记得所有用到它的地方都要换：代码、环境变量、手机 App、电脑
